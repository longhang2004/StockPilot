# U3 Receipt/SKU/audit/integration source navigation

## Implementation

- Receipts workspace is a document list backed by `GET /receipts` with `page`/`search` in URL state; selecting a receipt pushes `receipt=<uuid>` and renders a contextual object view (supplier, reference/date/note, line quantities/costs, product links into inventory trace) from `GET /receipts/:id`. Movement rows in the legacy drawer are superseded by the document page.
- Inventory selection deep link `inventory?product=<uuid>` explains on-hand/reserved/available, reservations from confirmed order lines (order/customer/quantity), and paginated source-bearing movements; source rows link to `/app/receipts?receipt=...`; list rows link to `/app/inventory?product=...`.
- Audit accepts URL filters `entityType` and `entityId` (matching the new `entityId` API filter), shows a scoped-context notice with a one-click clear action, and keeps list state when closing an object.
- Integrations selection uses `delivery=<uuid>` with `page`/`search`/`status` in URL state.
- Shared URL helper `features/shared/use-workspace-location.ts` clones current search params, deletes keys on `null`/`''`/`undefined` (read-only `useSearchParams` clone per Next docs), preserves unknown parameters, and exposes `href(patch)` plus `update(patch, mode)` with push/replace semantics and `scroll:false`. Object navigation uses push; filter changes use replace.
- Gating follows the root RBAC review: STAFF does not fetch or render protected delivery objects; protected actions stay Manager/Owner.
