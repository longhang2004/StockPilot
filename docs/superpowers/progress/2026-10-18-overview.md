# U2 Overview actionable worklist

## Implementation

- Replaced the exception-count-first overview content with three bounded, independently queried lists: draft orders, open low-stock alerts, and failed integration deliveries. Rows identify the underlying record and link directly to the existing Orders, Inventory, and Integrations detail selection routes.
- Each list requests five rows at a time, exposes a visible total only after a successful response, has independent loading/error/empty handling, and includes pagination plus a route-level “view all” link. `refetchOnMount: 'always'` refreshes the queries after navigating back to Overview; the structured query keys match the existing `usePage` cache keys.
- STAFF draft actions say “Edit draft”; MANAGER/OWNER actions say “Review draft”. Low-stock alerts only link to current stock (“View stock”), and show `availableAtOpen` explicitly as historical alongside the reorder point. Delivery timestamps say “received” because `createdAt` is not a failure timestamp.
- Kept recent movements, recent orders, movement history, and analytics as supporting content below the worklist. The demo guide now omits manager-only confirm/audit instructions for STAFF.
- Made the movement chart tolerate an older partial overview fixture without crashing.
