# StockPilot visual implementation handoff

## Direction implemented

The web app now uses a cool light canvas, white data surfaces, navy global structure, action blue, and Adobe Source Sans 3. The authenticated shell is a full-width navy bar for brand/workspace/session controls above a light grouped navigation rail and a white workspace. Navigation groups are Operations, Records, and Review. Mobile retains the four labeled Overview, Orders, Inventory, and More destinations. The landing page is concise and task-oriented, with role entry and an honestly labeled illustrative inventory worklist instead of the former screenshot-led marketing layout.

`design-system/stockpilot/MASTER.md` now records the topbar/light-rail composition. The app uses native React/HTML components; no design-system framework migration was made. Numeric values use Source Sans 3 tabular figures. Monospace remains only for actual JSON/payload preview.

## Implementation contracts for feature work

- Global font: `--font-sans`; quantities, prices, dates, and aligned identifiers use `font-variant-numeric: tabular-nums`; reserve `--font-mono` for code/JSON.
- Semantic colors include `--color-border-strong`, `--color-border-subtle`, `--surface-success`, `--surface-warning`, and `--surface-danger`; legacy route aliases remain available.
- The top shell is `.workspace-topbar`; its content grid is `.workspace-layout`; side navigation is `.workspace-sidebar`; content is `.workspace-main`. Sidebar links keep `.workspace-nav-link` and `.workspace-nav-active` and include `aria-current="page"`.
- Existing worklist feature selectors (`.page-header`, `.search-filter-bar`, `.data-surface`, `.operations-table`, `.responsive-table-wrap`, `.mobile-record-list`) remain intact for route/feature workers. The future `features/shared/operations-detail.css` remains outside this lane.
- Demo role switching and workspace switching remain the existing API-backed controls, now in the header. Grouped nav preserves all existing destinations. No bulk-action feature was added.
