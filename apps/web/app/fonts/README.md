# StockPilot interface font

- Family: Source Sans 3 variable, upright, WOFF2.
- File: `source-sans-3-vf.woff2`.
- Source: [Adobe Fonts `source-sans`, release/WOFF2/VF](https://github.com/adobe-fonts/source-sans/tree/release/WOFF2/VF), file `SourceSans3VF-Upright.ttf.woff2`.
- License: [SIL Open Font License 1.1](https://github.com/adobe-fonts/source-sans/blob/release/LICENSE.md), copied to `SOURCE-SANS-OFL-1.1.txt`.

The file is self-hosted through `next/font/local`; the browser makes no font request to a third-party host. Keep the license with the bundled font.
